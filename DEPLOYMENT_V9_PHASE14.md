# MAIN V9.3 — Fase 14

## Objetivo
Convertir el soporte preparado en V9.2 en una gestión real de evidencias múltiples para el contenido de los informes.

## Despliegue
1. Ejecutar `SUPABASE_V9_3_PHASE14.sql` en Supabase SQL Editor.
2. Sustituir los archivos del branch `main` por esta carpeta.
3. Esperar el despliegue de Vercel.
4. Recargar sin caché.

No requiere Edge Function nueva.

## Pruebas
- Crear una buena práctica con 3 fotografías y un PDF.
- Verificar miniaturas, visor y descarga.
- Cambiar la evidencia principal.
- Editar las leyendas.
- Reordenar evidencias.
- Quitar una evidencia con confirmación.
- Generar PDF y PPTX; las fotografías deben incorporarse al exportable.
- Archivar el registro; debe desaparecer sin dejar vínculos activos.
