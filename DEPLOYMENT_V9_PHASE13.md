# MAIN V9.2 — Fase 13

## Objetivo
Mejorar el módulo **Contenido de informes** para que funcione como tablero de preparación del informe semanal/mensual, con estado por sección, métricas claras y editor más guiado.

## Pasos
1. Ejecutar `SUPABASE_V9_2_PHASE13.sql` en Supabase SQL Editor.
2. Sustituir los archivos del branch `main` por el contenido del paquete.
3. Esperar despliegue de Vercel y recargar sin caché.

## Validación
- Abrir `Contenido de informes`.
- Cambiar semanal/mensual y confirmar que las secciones se adaptan.
- Ver tarjetas separadas para registros, sección seleccionada, evidencias y pendientes.
- Agregar un registro y verificar que el editor conserva los campos necesarios del informe.
- Ir a Exportaciones y verificar que los reportes sigan usando el contenido del periodo.
